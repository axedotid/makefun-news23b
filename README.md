# Sum up 23 November 2026 world news in one image

A Python/PIL program renders a single 1024x1024 editorial graphic summarising the
day's world news, then `main.ts` copies it to `/output/entry.png`.

## Usage

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out python3 build_image.py
MAKEFUN_OUTPUT_DIR=out node main.ts
```
